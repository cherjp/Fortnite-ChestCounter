**日本語** · 下の **`ChestCounter.exe`** をダウンロードして実行してください。インストールは不要です。1.6.0 以前をお使いの場合は、ホームの **インストール** ボタンか、exe を置き換えるだけで更新できます。履歴と設定はそのまま引き継がれます。

> **まずFortniteでリプレイを有効にしてください**: *設定 → ゲーム → リプレイ → リプレイを記録: オン*。このツールはリプレイファイルを読むだけで、ゲームの改変やメモリへのアクセスは一切しません。インターネットへの接続はGitHubのみです（新しいバージョンの確認〈オフにできます〉、お宝探しのデータ、初回だけのお宝の画像）。

**1.6.1 の新機能**
- **カード型オーバーレイ**: 左に宝箱、右に「宝箱 ───」の見出しと大きな合計、その右に 前回・セッション・お宝 を並べた新しいスタイルです。試合中は見出しの右に「● 試合中」が出ます。OBS 用ページも同じ見た目になります。新しく使い始める場合の既定で、今お使いの場合は *オーバーレイ → スタイル → カード* で選べます
- **宝箱の絵を差し替え**: データフォルダー（`%APPDATA%\ChestCounter`）に `overlay-chest.png` を置くと、カードの宝箱がその絵になります（透過 PNG 推奨。画像は PC の外に出ません）
- 1.6.0 の日本語対応・試合時間・平均・効率・履歴タブは [1.6.0 のリリース](https://github.com/cherjp/Fortnite-ChestCounter/releases/tag/v1.6.0) を参照してください

Windowsに「WindowsによってPCが保護されました」と表示された場合（署名のないexeのため）: *詳細情報 → 実行*。

**English** · Download **`ChestCounter.exe`** below and run it. Nothing to install. Already using it? **Install** on the home tab, or replace the exe: your history and settings are kept.

> **Turn on replays in Fortnite first**: *Settings → Game → Replays → Record Replays: On*. The tool only reads these replay files: no game modification, no access to the game's memory. It only goes online to GitHub: the check for a new version (can be turned off), the treasure hunt data and, once, the treasure pictures.

**What's new in 1.6.1**
- **Card overlay**: a new style with the chest on the left, "CHESTS ────" over the big total, and last match, session and treasures beside it. During a match, "● IN MATCH" shows next to the heading. The OBS page looks the same. Default for new users; otherwise pick it in *Overlay → Style → Card*
- **Your own chest picture**: put `overlay-chest.png` in the data folder (`%APPDATA%\ChestCounter`) and the card shows it instead of the chest (a transparent PNG works best; the picture never leaves your PC)
- Japanese, match time, averages, efficiency and the History tab came with [1.6.0](https://github.com/cherjp/Fortnite-ChestCounter/releases/tag/v1.6.0)

Windows may show *"Windows protected your PC"* (unsigned exe): *More info → Run anyway*.

- **Ta propre image de coffre** : mets `overlay-chest.png` dans le dossier des données (`%APPDATA%\ChestCounter`) et la carte l'affiche à la place du coffre (un PNG transparent rend mieux ; l'image ne quitte pas ton PC)
